# String Basics

## Concept

A string is a sequence of characters.

Strings are commonly used to represent text and are one of the most frequently used data types in DSA problems.

In Java, strings are represented using the `String` class.

Java strings are immutable, which means that once a String object is created, its contents cannot be changed.

## When to Use

String techniques are useful when:

- We need to search for characters or substrings.
- We need to compare strings.
- We need to reverse or rearrange characters.
- We need to count character frequencies.
- We need to check palindromes or anagrams.
- We need to process words or sentences.
- We need to extract or modify parts of a string.

## Important String Operations

Common operations include:

- Finding the length.
- Accessing a character.
- Comparing strings.
- Extracting substrings.
- Searching for characters.
- Converting between strings and character arrays.

# Frequency Counting

## Concept

Frequency counting is a technique used to count how many times each element or character appears.

It is one of the most common patterns in DSA.

Instead of repeatedly scanning the input to count occurrences, we store the count of each value in a frequency data structure.

The most common implementations are:

- Frequency Array
- HashMap
- HashSet

## When to Use

Frequency counting is useful when:

- We need to count characters.
- We need to count numbers.
- We need to find duplicates.
- We need to find unique elements.
- We need to find the most frequent element.
- We need to compare two collections.
- We need to determine whether an element has appeared before.
- The problem depends on how many times something occurs.
